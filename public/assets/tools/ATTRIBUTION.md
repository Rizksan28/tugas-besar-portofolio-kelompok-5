## Notes

- **Microsoft Teams and Excel:** Simple Icons removed Microsoft logos at
  Microsoft's request. Microsoft's official icon pack
  (learn.microsoft.com/microsoft-365/solutions/architecture-icons-templates)
  is licensed only for "architectural diagrams, training materials, or
  documentation". A portfolio website is outside that scope, so these files
  come from the community icon sets listed above.
- The Teams, SAP and Excel files were converted from Iconify JSON into
  standalone SVGs. No paths were changed.
- None of the files load external resources or contain scripts.
- The specialization icons in `src/components/expertise/SpecializationCard.tsx`
  use path data from Lucide (`lucide-static@0.468.0`, ISC License,
  https://lucide.dev).
